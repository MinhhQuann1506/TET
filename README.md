# 🧧 Game Lì Xì Ngày Tết (Lunar New Year Red Envelope Game)

Game lật hình phong bì Lì Xì ngày Tết trên trình duyệt web, tối ưu giao diện màn hình điện thoại (Mobile-First) không cuộn trang.

## 🎴 Cơ cấu bộ bài (20 lá)

* 💵 **12 ô Tiền mặt** (Tổng tiền trong bộ bài = 220.000 VNĐ):
  * `50k VND`: 2 ô (100k)
  * `20k VND`: 3 ô (60k)
  * `10k VND`: 5 ô (50k)
  * `5k VND`: 2 ô (10k)
* ✂️ **6 ô Giảm nửa (`÷ 2`)**: Giảm nửa số tiền đang có.
* 💀 **2 ô Phá sản (`BANKRUPT`)**: Mất toàn bộ số tiền và kết thúc game.
